## UI Integration

- Bell icon in AppHeader with unread count badge
- Badge shows "99+" for counts over 99
- Click opens notification panel/list
- Role-based: only 'notifications' feature permitted roles see it

## Escalation Notifications

Generated by escalation rules engine:
- Severity levels: 🟡 Warning, 🔴 Critical, 🟠 Overdue
- Staff message vs customer message templates
- Creates both Notification and ComplaintTimeline entries atomically
